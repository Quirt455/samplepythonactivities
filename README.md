# Distance Calculator

## Description

The program calculates the distance between two points using the distance formula.

You enters the x and y coordinates of two points, and the program calculates the distance between them. The result is rounded to two decimal places.

## How to run the program

1. Run the file.
2. Enter the x and y coordinates when the program prompts you.
3. Then the program will display the distance between the two points.

## Inputs needed

Inputs:

x1:  
y1: 
x2:  
y2: 

## Sample output
x1: 2
y1: 3
x2: 7
y2: 8

Output: 7.07
Distance: 7.07
